# Bot Panel আপডেট — যা যা যোগ/পরিবর্তন হলো

## নতুন ফিচার
1. **লগইন স্ক্রিন** — অ্যানিমেটেড অরোরা ব্যাকগ্রাউন্ড, তারা (stars) ড্রিফট এফেক্ট, গ্লোয়িং গ্রেডিয়েন্ট বর্ডার কার্ড, শাইনিং টাইটেল টেক্সট। সবই CSS-only (কোনো ভারী JS/ক্যানভাস না), তাই RAM/GPU-তে বাড়তি চাপ পড়ে না।
2. **ফাইল ম্যানেজার** — প্রতিটা ফোল্ডার-হেডার এখন গ্রেডিয়েন্ট + কালার বর্ডার সহ, ফাইল রো-গুলো আরও গোছানো ও স্পষ্ট bullet-marker সহ।
3. **লগ ভিউয়ার** — হ্যাকার-টার্মিনাল স্টাইল: window-dot হেডার (লাল/হলুদ/সবুজ), স্ক্যানলাইন ওভারলে, ব্লিঙ্কিং কার্সর, LIVE ইন্ডিকেটর, প্রতি ৪ সেকেন্ডে অটো-রিফ্রেশ (শুধু লগ ট্যাব খোলা থাকলে), অটো-স্ক্রল টগল বাটন।
4. **"আরো" ট্যাব রিঅর্গানাইজ করা হয়েছে:**
   - 🛠️ সমস্যা সমাধান: Restart + **Clean Install** (node_modules ও package-lock.json মুছে ফ্রেশ npm install — এটা `ERR_MODULE_NOT_FOUND` জাতীয় ভাঙা প্যাকেজ এরর ঠিক করে)
   - 🗄️ **Full Backup**: পুরো bot/ ফোল্ডারের zip এক ক্লিকে ডাউনলোড
   - 📦 জিপ ডিপ্লয় এখন হোম স্ক্রিন থেকে সরিয়ে "আরো" ট্যাবে একটা কোলাপসড/অ্যাডভান্সড সেকশনে রাখা হয়েছে (ট্যাপ করলে খোলে) — হোম স্ক্রিনে ভুলবশত চাপ লাগার ঝুঁকি নেই।
5. **হোম ট্যাব** — শুধু কন্ট্রোল বাটন (Install+Start/Start/Stop/Restart) ও একটা ছোট "স্বাস্থ্য" নির্দেশিকা কার্ড, বাকি সব "আরো" ট্যাবে।

## ব্যাকএন্ডে যা যোগ হলো
- `GET /api/backup/zip?token=...` — bot/ ফোল্ডারের zip বানিয়ে ডাউনলোড রেসপন্স দেয় (node_modules/.git/tmp বাদে)
- `POST /api/bot/clean-install` — node_modules + package-lock.json ডিলিট করে fresh `npm install` চালায়

## কীভাবে বসাবেন
এই `server.js` ফাইলটা আপনার **bot-panel-host** GitHub রিপোতে বিদ্যমান `server.js`-এর জায়গায় বসিয়ে কমিট/পুশ করুন (এটা bot/ ফোল্ডারের ভেতরের ফাইল না, তাই প্যানেলের নিজস্ব ফাইল ম্যানেজার দিয়ে এডিট করা যায় না — GitHub-এই আপডেট করতে হবে)। Render GitHub রিপো থেকে অটো-ডিপ্লয় করা আছে, তাই পুশ করলেই কিছুক্ষণের মধ্যে নতুন প্যানেল লাইভ হয়ে যাবে।

সবচেয়ে সহজ উপায়:
1. GitHub-এ আপনার bot-panel-host রিপো খুলুন
2. `server.js` ফাইলে গিয়ে এডিট (pencil আইকন) চাপুন
3. পুরনো কনটেন্ট সব মুছে এই নতুন `server.js`-এর কনটেন্ট পেস্ট করুন
4. "Commit changes" চাপুন
5. Render নিজে থেকেই নতুন ভার্সন ডিপ্লয় করবে (কয়েক মিনিট লাগবে, Render ড্যাশবোর্ডে "Deploying" দেখাবে)

## (আপডেট ২) ফাইল ম্যানেজার — প্রকৃত ফোল্ডার-নেভিগেশন
আগের ভার্সনে ফোল্ডার শুধু "কোলাপসিবল গ্রুপ" ছিল, ভেতরে ঢোকা যেত না — এখন বদলে দেওয়া হয়েছে:
- ব্রেডক্রাম্ব বার (🏠 bot / commands / ... ) — যেকোনো ধাপে ট্যাপ করে সরাসরি সেখানে ফিরে যাওয়া যায়
- ফোল্ডারে ট্যাপ করলে ভেতরে ঢোকে (আইটেম-সংখ্যা দেখা যায়), "⬆️ .. উপরে যান" দিয়ে ফিরে আসা যায়
- "📁 নতুন ফোল্ডার" বাটন — খালি ফোল্ডারও তৈরি করা যায় (ভেতরে অদৃশ্য `.keep` মার্কার ফাইল রাখে)
- সার্চ বক্সে কিছু লিখলে পুরো bot/ জুড়ে ফ্ল্যাট রেজাল্ট দেখায়; খালি করলে আবার ফোল্ডার-নেভিগেশন মোডে ফিরে যায়
- নতুন ফাইল তৈরি এখন বর্তমানে যে ফোল্ডারে আছেন সেখানেই হয় (পুরো পাথ লেখা লাগে না)

## (আপডেট ৩) আসল সমাধান: EADDRINUSE ক্র্যাশ
**কারণ:** প্যানেল নিজে Render-এর PORT (১০০০০)-এ শোনে। বট সাবপ্রসেস চালু হওয়ার সময় প্যানেলের env ইনহেরিট করে, তাই বটও একই PORT=10000-এ বাঁধার চেষ্টা করত — দুইটা প্রসেস একই পোর্টে শুনতে পারে না, তাই বট সাথে সাথেই ক্র্যাশ করত (`EADDRINUSE`)।

**সমাধান:**
- বট সাবপ্রসেসকে এখন জোর করে একটা আলাদা অভ্যন্তরীণ পোর্টে (`3000`) চালানো হয় — bot/.env-এ PORT যাই থাকুক না কেন, প্যানেল spawn করার সময় override করে দেয়।
- যেহেতু Meta-র webhook শুধু প্যানেলের পাবলিক URL-এ পৌঁছাতে পারে (bot-এর ভেতরের পোর্টে সরাসরি না), প্যানেলে এখন `GET/POST /webhook` একটা প্রক্সি রুট যোগ করা হয়েছে যেটা রিকোয়েস্ট ভেতরে ভেতরে বট-এর 3000 পোর্টে ফরওয়ার্ড করে দেয়। এটা ছাড়া webhook verify/মেসেজ কখনোই বট পর্যন্ত পৌঁছাত না।

এই ফিক্সের পর "Restart" চাপলেই বট আর ক্র্যাশ করবে না, এবং Meta Webhook URL হিসেবে যা আগে দিয়েছিলেন (`https://<panel>.onrender.com/webhook`) সেটাই ঠিক থাকবে — নতুন করে কিছু বদলাতে হবে না।

## (আপডেট ৪) আসল কারণ: Stop/Restart চাপলেই নিজে থেকে দ্বিতীয় কপি চালু হয়ে যাচ্ছিল
আগের কোডে একটা লজিক-বাগ ছিল: বট বন্ধ (Stop/Restart) করলেও প্যানেল সেটাকে "ক্র্যাশ" ধরে নিয়ে ৫ সেকেন্ড পর নিজে থেকেই আরেকটা `node index.js` চালু করে দিত — কারণ প্যানেলের কাছে "ইচ্ছাকৃত বন্ধ" আর "হঠাৎ ক্র্যাশ"-এর মধ্যে কোনো পার্থক্য ছিল না। এর ফলে:
- মাঝে মাঝে দুইটা বট প্রসেস একসাথে একই পোর্টে (3000) বাঁধার চেষ্টা করত
- দ্বিতীয়টা `EADDRINUSE` দিয়ে সাথে সাথেই ক্র্যাশ করত
- সেই ক্র্যাশ আবার নতুন অটো-রিস্টার্ট ট্রিগার করত — এভাবে ক্র্যাশ-লুপ শুরু হয়ে "৩০ মিনিটে ৪ বার ক্র্যাশ" লকডাউনে গিয়ে ঠেকত

**সমাধান:**
- `startBot()` এখন চেক করে — বট ইতিমধ্যে চলমান থাকলে দ্বিতীয়টা চালু করবে না
- `stopBot()` এখন একটা `intentionalStop` ফ্ল্যাগ ব্যবহার করে — ইচ্ছাকৃত বন্ধের পর প্রসেস সত্যিই বন্ধ হলে প্যানেল বুঝে নেয় এটা ক্র্যাশ না, তাই অটো-রিস্টার্ট ট্রিগার করে না
- Restart/Clean-Install বাটন এখন পুরনো প্রসেস **সত্যিই বন্ধ হওয়ার পরই** নতুনটা চালু করে (আগের মতো আন্দাজে ১ সেকেন্ড অপেক্ষা না করে)

এই ফিক্সের পর "রিস্টার্ট" বা "Stop" বারবার চাপলেও আর ক্র্যাশ-লুপে পড়ার কথা না।
